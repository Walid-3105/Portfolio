This is a modern, responsive portfolio website built with **React**, **Vite**, **Tailwind CSS**, and **React Router** as part of the internship selection process for CodesRaft.

## 🌐 Live Site

[👉 View Deployed Website](https://flossy-portfolio.netlify.app)

## 📂 GitHub Repository

[👉 View Source Code](https://github.com/Walid-3105/Portfolio.git)

---

## 🔧 Tech Stack

- **React** – Frontend Library
- **Vite** – Fast build tool for React
- **Tailwind CSS** – Utility-first CSS framework
- **React Router DOM** – Page navigation

---

## 📄 Pages Included

1. **Home**
2. **Blog**
3. **Contact**

---

## 📌 Features

- Fully responsive design
- Clean and modern UI inspired by a Dribbble design
- Functional routing with `react-router-dom`
- Reusable components
- Deployed on Netlify

---

## 🚀 Getting Started (Development)

Clone the project and run locally:

```bash
git clone https://github.com/Walid-3105/Portfolio.git
cd portfolio
npm install
npm run dev


```
